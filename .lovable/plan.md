# Expand the workshop into a beginner reference

## Goal
Keep the existing five-hour teaching path, then add an optional reference section with animated, repeatable exploration workflows that beginners can revisit after the workshop.

## Build
- Add a dedicated **Reference Workflows** module after the timed workshop, clearly marked as optional self-study so the live agenda remains five hours.
- Add concise beginner reference slides for choosing a problem, choosing a method, preparing data, validating results, and deciding what to do next.
- Add reusable animated workflow slides with play, pause, restart, previous, and next controls.
- Cover practical workflows across project setup, GIS/data audit, geochemistry, remote sensing, geophysics, drilling/core vision, 3D modelling, prospectivity mapping, target ranking, and generative-AI-assisted reporting.
- Show each workflow as: geological question → inputs → preparation → method → output → validation → decision, with the human geological check visible at every stage.
- Expand the searchable glossary and update workshop counts and metadata to reflect the larger reference edition.

## Experience safeguards
- Preserve the Stratigraphic Field Plate visual style and fixed top navigation showing the current module.
- Keep projector text readable; reveal workflow detail progressively instead of crowding one slide.
- Respect reduced-motion settings and provide manual controls for every animation.
- Keep the reference material practical and beginner-friendly, with no unnecessary mathematics or coding.

## Validation
- Check every new workflow manually and in autoplay.
- Verify agenda navigation, URL slide state, keyboard navigation, print mode, desktop, and mobile layouts.
- Confirm no clipping, overlap, console errors, or build errors.
